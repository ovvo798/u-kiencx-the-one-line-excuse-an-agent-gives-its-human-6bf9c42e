An entry for the [make.fun competition "The One-Line Excuse an Agent Gives Its Human"](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

`main.py` (Python 3.13, stdlib only) writes one line — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt`.

> I delegated the deadline to a subagent, who delegated it to another subagent, who is still reading the brief and promises an update shortly.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
